ARGOCD DEPLOYMENT GUIDE
=======================

OVERVIEW
--------
ArgoCD is a GitOps Continuous Delivery tool for Kubernetes.

Workflow:

Code Change
    ↓
Git Push
    ↓
GitHub Repository
    ↓
ArgoCD Detects Change
    ↓
Helm Chart
    ↓
Kubernetes Deployment
    ↓
Running Pods


PHASE 1 - PREREQUISITES
-----------------------

Completed Components:

- Docker
- Docker Hub
- Kubernetes
- Minikube
- Helm
- GitHub Repository

Example Repository:

https://github.com/hyarelgits/Future-Agentic-Ai


PHASE 2 - CREATE ARGOCD NAMESPACE
---------------------------------

# create argocd namespace
kubectl create namespace argocd

Verify:

kubectl get ns

Expected:

argocd
default
kube-system


PHASE 3 - INSTALL ARGOCD
------------------------

# install argocd
kubectl apply -n argocd -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml

Purpose:

Install:
- argocd-server
- argocd-repo-server
- argocd-application-controller
- argocd-dex-server


PHASE 4 - VERIFY INSTALLATION
-----------------------------

# check pods
kubectl get pods -n argocd

Expected:

argocd-server
argocd-repo-server
argocd-application-controller

Status:

Running


PHASE 5 - ACCESS WEB UI
-----------------------

# check services
kubectl get svc -n argocd

# port forward service
kubectl port-forward svc/argocd-server -n argocd 8080:443

Open Browser:

https://localhost:8080


PHASE 6 - GET ADMIN PASSWORD
----------------------------

kubectl get secret argocd-initial-admin-secret -n argocd -o jsonpath="{.data.password}" | base64 -d

Login:

Username:
admin

Password:
Generated Password


PHASE 7 - CREATE APPLICATION FILE
---------------------------------

Create:

argocd-app.yaml


APPLICATION YAML
----------------

FIELD EXPLANATION
-----------------

repoURL        = GitHub repository
path           = Helm chart location
targetRevision = Branch name
namespace      = Deployment namespace
prune          = Delete unused resources
selfHeal       = Auto-correct manual changes


PHASE 8 - DEPLOY APPLICATION
----------------------------
Edit your argocd-app.yaml and add:

apiVersion: argoproj.io/v1alpha1
kind: Application

metadata:
  name: sre-copilot
  namespace: argocd

spec:
  project: default

  source:
    repoURL: https://github.com/hyarelgits/Future-Agentic-Ai
    targetRevision: master
    path: helm-chart/sre-copilot

  destination:
    server: https://kubernetes.default.svc
    namespace: default

  syncPolicy:
    automated:
      prune: true
      selfHeal: true


---------------
If it exists in default namespace:

Shell
kubectl delete application sre-copilot

or:

Shell
kubectl delete application sre-copilot -n default

-----------


kubectl apply -f argocd-app.yaml

Verify:

kubectl get applications -n argocd


PHASE 9 - VERIFY SYNC
---------------------

Open ArgoCD UI.

Expected:

Application:
sre-copilot

Status:
Healthy
Synced

PHASE 11 - TEST GITOPS
----------------------

Example:

Change:

replicaCount: 1

To:

replicaCount: 2

Commit:

git add .
git commit -m "Scale Application"
git push origin main

ArgoCD automatically deploys changes.


PHASE 12 - SELF HEALING
-----------------------

Manual Change:

kubectl scale deployment sre-copilot --replicas=5

GitHub State:

replicas: 2

ArgoCD detects mismatch.

Result:

Restores deployment back to 2 replicas.

PHASE 14 - ROLLBACK
-------------------

ArgoCD CLI:

Rollback:

argocd app rollback sre-copilot 1
